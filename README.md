## Запуск завдань

Кожен файл можна запустити напряму з кореневої папки проєкту (`~/ruby-labs`):

### 1. Статистика слів (`01_word_stats.rb`)
```bash
ruby work/01_word_stats.rb
```
Або через передачу рядка:
```bash
printf "Ruby is fun and ruby is powerful\n" | ruby work/01_word_stats.rb
```

### 2. Гра «Вгадай число» (`02_guess_number.rb`)
```bash
ruby work/02_guess_number.rb
```
- Комп'ютер загадує число від 1 до 100.
- Програма підказує «більше», «менше» або «вгадано».
- Ведеться підрахунок спроб. Перевіряється некоректне введення (порожній рядок, не ціле число, число поза межами 1..100).

### 3. Гра «Камінь, ножиці, папір» (`03_rock_paper_scissors.rb`)
```bash
ruby work/03_rock_paper_scissors.rb
```
- Вибір ходу: `1` (Камінь), `2` (Ножиці), `3` (Папір) або введенням тексту (`камінь`, `ножиці`, `папір`).
- Вихід з гри: `0`, `вихід` або `exit`.
- Правила збережені в структурі `Hash` (`RULES = { rock: :scissors, ... }`) без каскадних `if`.
- Поточна статистика виводиться після **кожного** раунду, а також у фінальному підсумку.

### 4. Пиріг з родзинками (`04_raisin_cake.rb`)
```bash
ruby work/04_raisin_cake.rb
```
- Запускає демонстрацію розрізання для обох прикладів із завдання (приклад 1: 4 горизонтальні смуги; приклад 2: форма 2×6 та три 6×2).
- Метод `cut(cake)` реалізований через бектрекінг: обхід першої незайнятої клітинки зверху-зліва та перебір прямокутників потрібної площі (де рівно одна родзинка), **ширші варіанти перевіряються першими**.
- Підтримує як латинську `o`, так і кириличну `о`, коректно видаляє зайві пробіли з опечаток умови.

### 5. Гра «Судоку 4×4» (`05_sudoku.rb`)
```bash
ruby work/05_sudoku.rb
```
- Поле 4×4 з блоками 2×2, задане в коді з гарантованим єдиним розв'язком.
- Введення ходу: `<рядок> <стовпець> <число>` (наприклад: `1 2 4`).
- Перевірка правил: унікальність у рядку, стовпці та блоці 2×2.
- Заборона зміни початкових чисел із поясненням причини.
- Додаткові команди:
  - `u` / `undo` — скасування останнього ходу.
  - `h` / `hint` — отримання підказки (знаходить порожню клітинку та пропонує число з правильного розв'язку).
  - `s` / `stats` — перегляд статистики успішних ходів, помилок і скасувань.
  - `q` / `exit` — вихід з гри.

### 6. Гра «Морський бій» (`06_sea_battle.rb`)
```bash
ruby work/06_sea_battle.rb
```
- Меню: `1` — нова гра, `2` — правила, `3` — статистика, `0` — вихід.
- Поле 10×10 (стовпці A–J, рядки 1–10). На екрані два поля: своє (видно кораблі) і поле комп'ютера (видно лише влучання `X` і промахи `•`).
- Флот розставляється автоматично: 1×4, 2×3, 3×2, 4×1. Кораблі не перетинаються і не торкаються, навіть по діагоналі.
- Постріл — координата на кшталт `B7` або `J10`. Після пострілу гра повідомляє: промах, влучання або «корабель знищено». Влучили — стріляєте ще раз.
- Комп'ютер стріляє лише в нові клітинки: спочатку випадково, після влучання добиває корабель уздовж лінії.
- Некоректні координати, повторний постріл, порожній рядок, кінець введення і Ctrl+C не завершують програму аварійно.
- Статистика перемог і поразок зберігається між запусками у файлі `~/.sea_battle_stats.json`.

Структура коду (модуль `SeaBattle`, файли підключаються через `require_relative`):

| Файл | Що в ньому |
|---|---|
| `sea_battle/errors.rb` | власні помилки: `SeaBattle::Error` → `InvalidCoordinateError`, `AlreadyShotError`, `PlacementError` |
| `sea_battle/coordinate.rb` | клас `Coordinate`: розбір «A5» з `raise InvalidCoordinateError`, сусідні клітинки |
| `sea_battle/ship.rb` | клас `Ship`: клітинки, влучання, `sunk?` |
| `sea_battle/board.rb` | клас `Board`: розстановка флоту, перевірка правил, обробка пострілу |
| `sea_battle/computer_player.rb` | клас `ComputerPlayer`: вибір пострілу без повторів |
| `sea_battle/statistics.rb` | клас `Statistics`: перемоги/поразки, збереження в JSON |
| `sea_battle/renderer.rb` | клас `Renderer`: виведення двох полів |
| `sea_battle/game.rb` | клас `Game`: партія, ходи, `rescue` помилок введення |
| `sea_battle/menu.rb` | клас `Menu`: головне меню |

## Запуск тестів (Minitest)

Усі тести написані з використанням стандартної бібліотеки `Minitest` і проходять без попереджень (`ruby -w`).

### Запуск усіх тестів разом:
```bash
ruby -w -Iwork work/test/all_tests.rb
```

### Запуск окремих тестових файлів:
```bash
ruby -w -Iwork work/test/test_01_word_stats.rb
ruby -w -Iwork work/test/test_02_guess_number.rb
ruby -w -Iwork work/test/test_03_rock_paper_scissors.rb
ruby -w -Iwork work/test/test_04_raisin_cake.rb
ruby -w -Iwork work/test/test_05_sudoku.rb
ruby -w -Iwork work/test/test_06_sea_battle.rb
```
